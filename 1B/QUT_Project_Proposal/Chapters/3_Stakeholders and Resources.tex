\section{Resources}
Training and optimizing Gaussian splatting models requires significant computational power and high-quality data. Successful completion of this project requires the following key resources:
\begin{itemize}
    \item \textbf{Dataset:} The AIMS EcoRRAP dataset will serve as the core testing foundation. This high-fidelity dataset contains time-series field photogrammetry of coral reef clusters, which is absolutely essential for training and validating the change detection pipeline.
    \item \textbf{Computing Hardware:} Training Gaussian Splatting models is a memory and compute-intensive process. The project necessitates access to a high-performance workstation equipped with a top-tier NVIDIA GPU boasting a minimum of 24 GB of VRAM (For example a NVIDIA RTX 3090, RTX 4090, or A-series equivalents) to handle the optimization of millions of 3D primitives without running out of memory.
    \item \textbf{Software \& Frameworks:} Python for script development, PyTorch for executing 3DGS optimizations, and specialized 3DGS CUDA kernels. Agisoft Metashape or COLMAP may also be required for initial camera pose estimations (Structure from Motion) prior to splatting.
\end{itemize}
