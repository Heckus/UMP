\chapter{Deliverables}

The project is expected to yield the following key deliverables upon completion:

\begin{enumerate}
    \item \textbf{Final Project Report:} A comprehensive thesis document detailing the theoretical background, methodological approach, implementation specifics, and evaluation results of the underwater scene change detection pipeline.
    \item \textbf{Working Code Repository \& Pipeline:} A fully operational, documented, and reproducible codebase that executes the selected underwater 3DGS reconstructions and the primitive-space change detection algorithm.
    \item \textbf{Detailed 3D Gaussian Splat Models:} High-fidelity, water-removed 3D Gaussian Splatting reconstructions of the AIMS EcoRRAP coral reef datasets, serving as the foundational maps.
    \item \textbf{Dataset of Change Maps:} A comprehensive set of extracted change maps (Geometric, Colour, and Full) demonstrating structural changes and anomalies across the temporal datasets.
    \item \textbf{Project Presentation:} A final presentation delivered to the supervisory team, stakeholders, and QUT faculty, providing an overview of the pipeline's capabilities and the results achieved on the coral datasets.
\end{enumerate}
